## ⟢ What I Build

I work at the intersection of **embedded systems, firmware, low-level programming, and software engineering**.

My primary focus is **Ada**, especially for building reliable and portable software that can span from resource-constrained embedded systems to general-purpose computers.

I enjoy building things from the fundamentals — understanding the hardware, designing the abstractions, and turning them into reusable software.

## ⟢ My Approach

```text
Understand the hardware
        ↓
Build the low-level foundation
        ↓
Design clean abstractions
        ↓
Make it portable
        ↓
Turn it into reusable software
```

I prefer **understanding how things work underneath the abstraction** rather than treating the abstraction as a black box.
